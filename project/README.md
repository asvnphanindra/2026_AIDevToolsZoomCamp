# Work Planner

Interactive daily / weekly planner for one person: plan blocks on a grid, drag tasks onto time, mark **Done / Partly / Not done**, and keep life areas (Job, PhD, Family, Passion) visible. Replaces a static morning PNG generated by a Python script.

**Course:** AI Dev Tools Zoomcamp 2026 — final project (attempt 2)  
**Stack:** React + TypeScript · Firebase Auth (Google) · Cloud Firestore · Emulators for local/CI (Firebase Hosting **after** course submission)  
**Timezone:** Asia/Kolkata (IST) · **Privacy:** demo seed for reviewers; personal data stays out of git

## Problem

The current planner is a script that renders an image each morning. Changes (substitute class, holiday, appointment) require regenerating the whole image. Tasks cannot be dragged, resized, or marked done in place. There is no history of what got done, so every-3-weeks PhD status updates are harder to write. Productivity bands, life areas, and recurring rules live in code instead of editable data.

## Features (MVP)

- **3-day hourly grid** (today + next 2) and **rolling week** view; month calendar markers
- **Tasks + time blocks** coloured by life area; grey routine blocks; class blocks from a seeded timetable
- **Drag / move / resize** from backlog onto the grid; conflict warnings
- **Daily rules:** suggest (never auto-force) a 1.5 h PhD deep-focus block; warn if missing
- **Status after end time:** Done / Partly / Not done → partly/not done return to backlog with replan
- **Focus Tasks** panel (four life areas) and **weekly goals** with carry-over
- **Day types:** Holiday / No classes / Online / Exam (seeded timetable; no import UI in MVP)
- **3-week horizon** for goals/tasks by day; data model ready for month/quarter later

## Expected behavior

1. Sign in with Google (demo: anonymous or demo Google so reviewers never see personal data).
2. Open Day view → see routines, classes, and planned blocks for today (IST).
3. Create a task → drag onto a free slot → resize → save.
4. Overlap a class/meal → app warns and offers shorten/move.
5. After a block ends → prompt Done / Partly / Not done; unfinished items return to backlog.
6. Mark a date Holiday → campus/bus blocks hide for that day.
7. Weekly goals show progress; unfinished goals can carry to next week in one click.

## Non-goals (MVP)

- Multi-user sharing · scheduled push to a closed phone (Blaze) · full 3-month / 3-quarter planning UI · PNG export · personal data in the public demo
