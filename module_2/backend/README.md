# Backend

FastAPI API for Mini Kanban (`module_2`). Implements `../openapi.yaml`.

## Setup

```bash
uv sync
```

## Run

```bash
uv run uvicorn app.main:app --reload --port 8000
```

## Tests

```bash
uv run pytest
```
